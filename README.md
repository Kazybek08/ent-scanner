# ҰБТ-сканер / ЕНТ-сканер

Бесплатное веб-приложение (PWA) для iPhone: проверяет бланки пробного ЕНТ по фото или PDF и считает баллы.
Работает без сервера и без интернета после первой установки. Техническое задание — [docs/TZ.md](docs/TZ.md).

## Что уже готово (день 1)

- Каркас приложения: шесть разделов, переключатель ҚАЗ / РУС, работа без интернета (service worker).
- Генератор PDF бланка ответов v2 (раздел «Бланк басып шығару / Печать бланков»).
- Единый шаблон бланка `src/template.js` — по нему рисуется PDF и будет работать распознавание.

## Структура

| Путь | Что там |
|---|---|
| `index.html`, `css/`, `src/app.js` | приложение |
| `src/template.js` | координаты всех кружков и меток бланка (мм) |
| `src/sheet-pdf.js` | рисование PDF бланка |
| `src/subjects.js` | предметы и блоки теста |
| `i18n/kk.json`, `i18n/ru.json` | все тексты интерфейса |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на iPhone и офлайн |
| `vendor/` | библиотеки (jsPDF) и шрифт DejaVu с казахскими буквами |
| `tests/` | автотесты |
| `tools/` | служебные скрипты для ноутбука |
| `test-sheets/` | фото заполненных бланков для проверки распознавания |

## Команды на ноутбуке

```bash
npm install        # один раз: скачать библиотеки для разработки
npm test           # автотесты
npm run sheet      # собрать out/blank-v2.pdf
npm run serve      # открыть приложение на http://localhost:8080
```

После изменения любых файлов приложения увеличьте `VERSION` в `sw.js`, иначе iPhone покажет старую версию.
