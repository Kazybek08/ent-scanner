# ҰБТ-сканер / ЕНТ-сканер

Бесплатное веб-приложение (PWA) для iPhone: проверяет бланки пробного ЕНТ по фото или PDF и считает баллы.
Работает без сервера и без интернета после первой установки. Техническое задание — [docs/TZ.md](docs/TZ.md).

## Что уже готово (день 1)

- Каркас приложения: шесть разделов, переключатель ҚАЗ / РУС, работа без интернета (service worker).
- Генератор PDF бланка ответов v2 (раздел «Бланк басып шығару / Печать бланков»).
- Единый шаблон бланка `src/template.js` — по нему рисуется PDF и будет работать распознавание.

## День 2: распознавание

- `src/omr.js` — распознавание без сторонних библиотек: выравнивание освещения → 4 угловые метки →
  перспектива → ориентация по коду версии (бланк можно снимать боком и вверх ногами) → заливка кружков.
- Пороги: ≥ 0,55 — закрашен, 0,15–0,55 — сомнительно (подсветка), меньше — пусто.
- Раздел «Сканирование»: фото с камеры, фото из галереи, многостраничный PDF; отметки поверх фото.
- Проверка: `npm test` (искусственные бланки), `node tools/stress-omr.mjs 60` (нагрузочный прогон),
  `tools/lab-lib.js` — «фото» настоящего бланка из PDF в браузере.

## День 3: ученики, ключи, баллы

- «Ученики»: добавление вручную и из Excel, постоянный ID из 4 цифр (не повторяется даже после удаления),
  отметка «выбыл», печать списка «ФИО — ID» в PDF.
- «Пробники и ключи»: пробник с датой, шаблон ключей, загрузка ключей с проверкой (пропуски, буквы,
  русские А/В/С/Е → латинские), понятный список ошибок с номерами строк.
- Подсчёт баллов `src/scoring.js` (автотесты: 2/1/0 для 31–40, два кружка = 0, нет ключа ≠ 0).
- Сканы сохраняются в памяти телефона (IndexedDB) вместе с фото; предупреждения: неизвестный ID,
  повтор ID в пробнике, нет ключа для варианта или предмета.
- Шаблоны Excel: `docs/keys-template-ru.xlsx`, `docs/students-template-ru.xlsx` (и `-kk`).

## День 4: проверка и исправления

- «Проверка и результаты»: бланки с замечаниями по порядку сканирования, «Начать проверку» → «Сохранить и следующий».
- Редактор бланка (`src/editor.js`): карточки сомнительных мест с выпрямленным вырезом строки из фото (`src/crop.js`),
  кнопки букв, «Нет ответа», «Оставить как распознано»; исправление ID (имя ученика сразу), варианта, предметов;
  дубли ID с переходом к другому скану; все 120 ответов списком; удаление скана.
- Исправления хранятся отдельно от распознанного (`edits`), итог и баллы — `src/results.js` (автотесты).
- Офлайн: тест проверяет, что все модули, библиотеки и шрифты в списке service worker.

## День 5: результаты, Excel, резервная копия, настройки

- Вкладка «Результаты»: итоги, рейтинг (одинаковые места, последний скан ученика), фильтр по группе,
  средние по группам, карточка ученика с баллами по предметам, порогом и списком ошибок.
- Excel (`src/export-xlsx.js`, ExcelJS): «Итоги», «Ответы» (ошибки красным, пустые жёлтым), «Анализ вопросов»
  (топ-10 трудных), «Динамика»; язык файла — қаз или рус.
- Резервная копия (`src/backup.js`): один JSON-файл со всеми данными и фото → «Поделиться» → Google Диск;
  восстановление заменяет всё одной операцией; напоминание на главном экране.
- «Настройки»: пороги (общий + минимумы по предметам), пары предметов «Профиль 1 / Профиль 2», логотип, память.

## Бланк v3: формат настоящих пробников (26.11)

Профильный предмет: 1–30 — один ответ из A–D; 31–35 — сопоставление (пункты 1) и 2), у каждого один ответ
из A–D, балл за каждую верную пару: 2/1/0); 36–40 — от одного до трёх верных из A–F (2/1/0).
Обязательные блоки — по-прежнему A–E.

- `src/template.js`: тип вопроса (`questionType`), сопоставление — две строки кружков в одной строке бланка.
- Ключ сопоставления в Excel — две буквы по порядку пунктов: `CA` = 1)→C, 2)→A.
- Код версии внизу бланка: бланк старой версии (v2) не читается по новой разметке — приложение просит новый бланк.
- В тестах пункты сопоставления должны называться 1) и 2), варианты — A–D (как в химии).

## Бланк v4: порядок профилей на бланке (26.11)

- У каждого профильного предмета два кружка: «1» и «2». Ученик закрашивает «1» у предмета, который пишет
  в блок «Профиль 1», и «2» — у второго. Порядок профилей берётся с бланка, настройки «пары предметов» не нужны.
- Неясно (нет «1» или «2», две «1», «1» и «2» у одного предмета) — подсветка; в редакторе первый нажатый
  предмет — профиль 1, второй — профиль 2, есть кнопка «Поменять местами».
- Уже напечатанные бланки v3 по-прежнему читаются (порядок — по парам из настроек). Бланк v2 — ошибка.

## Структура

| Путь | Что там |
|---|---|
| `index.html`, `css/`, `src/app.js` | приложение |
| `src/template.js` | координаты всех кружков и меток бланка (мм) |
| `src/sheet-pdf.js` | рисование PDF бланка |
| `src/subjects.js` | предметы и блоки теста |
| `src/omr.js`, `src/overlay.js` | распознавание бланка и отметки поверх фото |
| `src/scan.js`, `src/image-input.js` | раздел «Сканирование», загрузка фото и PDF |
| `i18n/kk.json`, `i18n/ru.json` | все тексты интерфейса |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на iPhone и офлайн |
| `vendor/` | библиотеки (jsPDF) и шрифт DejaVu с казахскими буквами |
| `tests/` | автотесты |
| `tools/` | служебные скрипты для ноутбука |
| `test-sheets/` | фото заполненных бланков для проверки распознавания |

## Команды на ноутбуке

```bash
npm install        # один раз: скачать библиотеки для разработки
npm test           # автотесты
npm run sheet      # собрать out/blank-v4.pdf
npm run serve      # открыть приложение на http://localhost:8080
```

После изменения любых файлов приложения увеличьте `VERSION` в `sw.js`, иначе iPhone покажет старую версию.
