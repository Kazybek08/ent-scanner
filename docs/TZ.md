# ТЗ: Сканер бланков пробного ЕНТ

23.11.2026 · Kazybek

> Копия документа «ТЗ: Сканер бланков пробного ЕНТ» (Claude Docs). Главная версия — там; эту обновлять при изменениях.

## 1. Цель и рамки

Нужно бесплатное мини-приложение для iPhone, которое к 28.11.2026 проверяет бланки пробного ЕНТ по фото или PDF-скану и выдаёт баллы и аналитику без ручной проверки.

- **Пользователь:** один сотрудник учебного центра, один филиал.
- **Объём:** около 50 учеников (число растёт), пробник раз в месяц, в конце месяца.
- **Цель по времени:** проверка одного бланка не дольше 5 секунд вместо ручной сверки.
- **Бюджет:** 0 ₸. Платных серверов, API и подписок нет. Разработка — силами владельца через Claude Code на ноутбуке с Windows.
- **Не входит в проект:** доступ для учеников и родителей, проверка рукописных тестов с открытыми ответами, несколько филиалов.

## 2. Структура теста и начисление баллов

В тесте 120 заданий, максимум 140 баллов. Тесты составляет сам центр, в каждом пробнике два варианта.

| Блок | Вопросы | Варианты ответа | Верных ответов | Баллы за вопрос | Макс. балл |
| --- | --- | --- | --- | --- | --- |
| История Казахстана | 1–20 | 5 (A–E) | 1 | 1 | 20 |
| Математическая грамотность | 1–10 | 5 (A–E) | 1 | 1 | 10 |
| Грамотность чтения | 1–10 | 5 (A–E) | 1 | 1 | 10 |
| Профильный предмет 1 | 1–30 | 5 (A–E) | 1 | 1 | 30 |
| Профильный предмет 1 | 31–40 | 6 (A–F) | 1 или больше | 2 / 1 / 0 | 20 |
| Профильный предмет 2 | 1–30 | 5 (A–E) | 1 | 1 | 30 |
| Профильный предмет 2 | 31–40 | 6 (A–F) | 1 или больше | 2 / 1 / 0 | 20 |
| **Итого** | **120** | | | | **140** |

**Правила подсчёта:**

- Вопросы с одним ответом: 1 балл, если закрашен ровно один правильный кружок. Пусто или закрашено два и больше — 0 баллов.
- Вопросы 31–40: 2 балла за полностью верный набор, 1 балл за одну ошибку, иначе 0.
- «Одна ошибка» — это один лишний или один пропущенный кружок по сравнению с ключом. Пустой ответ — 0.
- Пороговые баллы по направлениям (например, 50, 70, 75) хранятся в настройках и редактируются вручную. Минимальные баллы по предметам тоже задаются в настройках.

**Профильные предметы (12):** Математика, Физика, Химия, Биология, География, Всемирная история, Информатика, Иностранный язык, Казахский язык, Казахская литература, Русский язык, Русская литература. Список редактируется в настройках.

## 3. Бланк ответов v2

Бланк занимает один лист А4 и печатается на ч/б принтере. За основу берётся пример от 23.11 с изменениями ниже. Приложение само генерирует PDF бланка для печати.

- **Шапка:** логотип курса слева, заголовок на двух языках: «СЫНАҚ ҰБТ — ЖАУАП ПАРАҒЫ / ПРОБНОЕ ЕНТ — БЛАНК ОТВЕТОВ».
- **Поля для руки:** ФИО, группа, дата, подпись. Приложение их не распознаёт, они нужны для ручной сверки.
- **ID ученика:** 4 цифры (0001–9999), клетки для записи и колонки кружков 0–9.
- **Вариант:** 2 цифры (01–99).
- **Профильные предметы:** один кружок у каждого из 12 предметов, ученик закрашивает ровно два. Какой из них «Профиль 1», а какой «Профиль 2», приложение берёт из списка комбинаций в настройках (например, Математика + Физика → Математика = Профиль 1).
- **Ответы:** История Казахстана, Мат. грамотность, Грамотность чтения, Профиль 1, Профиль 2. Кружки A–E, в вопросах 31–40 профиля — A–F.
- **Инструкция:** на двух языках, с примером правильного и неправильного закрашивания.
- **Метки для распознавания:** чёрные квадраты 6×6 мм по углам и маленький код версии бланка внизу.
- **Кружки:** диаметр не меньше 3,3 мм, буквы внутри светло-серые, чтобы не путаться с закрашенными при ч/б печати.

Открытый вопрос: нужен файл логотипа курса (PNG или SVG).

## 4. Функции приложения

В приложении шесть разделов. Рабочий порядок: ученики → пробник и ключи → печать бланков → сканирование → проверка → отчёты.

1. **Ученики.** Список: ФИО, группа, язык обучения (қаз/рус), статус (активен или выбыл). Каждому автоматически присваивается постоянный ID из 4 цифр. Учеников можно добавить вручную или импортом из Excel. Есть печать списка «ФИО — ID» для раздачи ученикам.
2. **Пробники и ключи.** Создание пробника (название, дата) и загрузка ключей из Excel. Приложение даёт скачать шаблон и проверяет файл: ни одного пропущенного вопроса, только допустимые буквы.
3. **Печать бланков.** Генерация PDF бланка v2 (раздел 3).
4. **Сканирование.** Два способа:
   - камера: бланки по одному, снимок делается сам, когда видны все 4 угловые метки;
   - файл: многостраничный PDF из «Заметок» iPhone или фото из галереи. Одна страница = один бланк, пачка до 60 страниц за раз.
5. **Проверка распознавания.** После скана показывается бланк с распознанными ответами поверх фото. Сомнительные места подсвечены жёлтым: слабо закрашенный кружок, два ответа в вопросе с одним ответом, неизвестный ID, не два отмеченных предмета. Оператор исправляет нажатием и сохраняет. Если тот же ID уже есть в этом пробнике, появляется предупреждение о дубле.
6. **Настройки.** Язык интерфейса, логотип, список предметов и их комбинаций, пороговые баллы, резервная копия и восстановление.

**Формат Excel с ключами:** один лист на вариант («01», «02»), в нём четыре столбца.

| Предмет | № | Ответ | Тема (необязательно) |
| --- | --- | --- | --- |
| История Казахстана | 1 | C | Казахское ханство |
| Математика | 34 | ACE | Логарифмы |

Ключи задаются для всех профильных предметов, которые сдают ученики. Столбец «Тема» нужен, чтобы находить трудные темы, которые повторяются из месяца в месяц: вопросы в пробниках каждый раз разные, а темы повторяются.

## 5. Отчёты и аналитика

По каждому пробнику приложение даёт три вида результатов: экраны в самом приложении, выгрузку в Excel и аналитический разбор в PDF.

| Отчёт | Что показывает |
| --- | --- |
| Баллы ученика | Баллы по 5 предметам и общий из 140, проход порога, список ошибок по вопросам |
| Рейтинг группы | Ученики по убыванию балла, фильтр по группе, средний балл группы по предметам |
| Динамика ученика | График общего балла и баллов по предметам от пробника к пробнику, изменение к прошлому месяцу |
| Трудные вопросы | Процент верных ответов по каждому вопросу и варианту, самый частый неверный вариант, топ-10 самых трудных |
| Повторяющиеся трудные темы | Темы, где верных ответов меньше 50% два пробника подряд и больше (по столбцу «Тема») |

**Excel-файл пробника:** листы «Итоги», «Ответы» (ответ каждого ученика на каждый вопрос, ошибки красным), «Анализ вопросов», «Динамика».

**Аналитический разбор (PDF):** 2–4 страницы для руководства и преподавателей. Средние баллы и сравнение с прошлым месяцем, сколько учеников прошли порог, лучшие ученики и лучший рост, ученики в зоне риска, трудные вопросы и темы по предметам.

Отчёты формируются на казахском или русском на выбор. Доступа для учеников и родителей нет.

## 6. Техническое решение

Это веб-приложение (PWA): оно устанавливается на экран «Домой» iPhone из Safari, работает без интернета и ничего не стоит. App Store не нужен.

| Часть | Решение | Цена |
| --- | --- | --- |
| Хостинг | GitHub Pages (HTTPS, нужен для камеры) | 0 |
| Распознавание бланка | OpenCV.js прямо на телефоне, без сервера | 0 |
| Чтение PDF из «Заметок» | pdf.js | 0 |
| Excel (импорт и экспорт) | SheetJS | 0 |
| Графики и PDF-отчёт | Chart.js, генерация PDF в браузере | 0 |
| Хранение данных | IndexedDB в памяти iPhone | 0 |
| Резервная копия | Файл копии + Excel через меню «Поделиться» → Google Диск | 0 |

**Распознавание, по шагам:** найти 4 угловые метки → выровнять перспективу → измерить заливку каждого кружка по координатам шаблона → сравнить с соседними кружками строки. Пороги заливки (ориентир): больше 55% — закрашен, 25–55% — сомнительно, меньше 25% — пусто. Пороги подбираются на настоящих бланках.

**Важно для сохранности данных:**

- Данные хранятся на одном iPhone. Приложение нужно установить на экран «Домой»: как обычная вкладка Safari оно может стереть данные после долгого перерыва.
- После каждого пробника приложение напоминает сохранить резервную копию в Google Диск. Из неё всё восстанавливается на новом телефоне.
- Автоматическая синхронизация с Google Диском требует настройки Google Cloud. Это бесплатно, но занимает время, поэтому перенесена на этап 2.
- Фото бланков сохраняются в сжатом виде (примерно 150 КБ) на случай спорных вопросов.

## 7. Двуязычность (қазақша / русский)

Казахский и русский поддерживаются во всех трёх частях: в интерфейсе, на бланке и в отчётах.

| Что | Как работает |
| --- | --- |
| Интерфейс | Переключатель «ҚАЗ / РУС» вверху экрана, выбор запоминается. Язык по умолчанию — казахский |
| Бланк | Один бланк для всех: каждая надпись и инструкция даны на двух языках («ТАЖ / ФИО») |
| Отчёты и Excel | Язык выбирается при выгрузке |
| Названия предметов | Хранятся в двух вариантах, Excel с ключами принимает любой из них |

Все тексты интерфейса хранятся в двух файлах переводов (kk.json, ru.json), в коде текста нет. Казахские тексты нужно вычитать сотруднику центра до запуска.
